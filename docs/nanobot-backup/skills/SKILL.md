# Skill Index

This directory contains backups of nanobot AgentSkills used by OptiTrade.

## Naming convention

Each subfolder is one AgentSkill. The folder name matches the skill's slug on disk
(`/root/.nanobot/workspace/skills/<slug>/`).

Each `SKILL.md` describes when and how the skill should be invoked.

## Index

See `INDEX.md` for a one-line description of each skill.
